# Nexa Digital – Creative Digital Agency

A modern and responsive single-page website for a creative digital agency, designed to showcase digital services with an elegant layout and interactive user experience.

## 🚀 About the Project

Nexa Digital is a creative digital agency website focused on presenting digital solutions through a modern, clean, and professional design.

## ✨ Features

- Modern and elegant user interface
- Fully responsive design
- Interactive elements
- Smooth navigation
- Clean and organized layout

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📂 Project Structure

- `index.html` – Website structure
- `style.css` – Website styling
- `script.js` – Interactive functionality
